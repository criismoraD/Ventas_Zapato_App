Arquitectura y Flujo Transaccional

Sistema POS SENATI ZAPATO - Recorrido del ciclo de vida de una venta

1. Catálogo e Inicio (Panel_De_Ventas)

El usuario inicia sesión y visualiza el Panel de Ventas. El sistema carga de forma concurrente el catálogo desde SQLite usando Dao_De_Producto.Obtener_Todos(). Las imágenes se procesan asíncronamente en segundo plano.

🛒

2. Selección de Productos

Al hacer clic en un calzado o usar el comando de voz del Chatbot, el producto se añade al JTable. El modelo MVC calcula reactivamente el Subtotal, el IGV y el Total. Se pre-valida el stock de manera visual (sin bloquear la BD aún).

📦

3. Confirmación (Dialogo_De_Pago)

Al presionar F12, se instancia un objeto Venta con sus Detalle_De_Venta. Se despliega el panel modal de pago donde el cajero elige Efectivo, Tarjeta, Yape o Plin y define el monto recibido, calculando el vuelto exacto.

💳

4. Transacción ACID (Procesador_De_Pagos)

El núcleo financiero entra en acción. Se desactiva el autocommit. Se valida el stock físico. Si es exitoso, se ejecuta un INSERT de la cabecera y el detalle, seguido de un UPDATE para descontar el stock. Todo se asegura con un commit() o se revierte con rollback() ante un fallo.

connection.setAutoCommit(false);
// Validar Stock
// Insertar Venta
// Restar Stock
connection.commit();
🔒

5. Cierre y PDF (Generador_De_Pdf)

Tras confirmarse la integridad de la base de datos, el sistema limpia el carrito. Se llama a la librería iText 7 para generar un PDF legal (Boleta de Venta) guardado en la carpeta /comprobantes. Simultáneamente se lanza una vista previa en pantalla (Dialogo_De_Ticket).

📄
